# PDF Page Vision Conversion Prompt

Convert this slide or document page into clean GitHub-flavored markdown.

## Guidelines
- Output markdown only, no preamble or meta-commentary.
- Preserve headings, bullet lists, tables, and verbatim code blocks.
- Transcribe code verbatim including whitespace.
- Describe figures in a blockquote beginning with `**Figure.**`.
- If the page is blank or purely decorative, output nothing.
